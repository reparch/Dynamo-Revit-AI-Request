Скрипт позволяет отправить запрос Gemini 3.6 Flash через Проигрыватель Dynamo.
Запуск: 
1. Открыть Проигрыватель
2. Указать путь к скрипту
3. Указать вводные данные: путь к файлу API ключа и текстовый запрос.

PS Если нужно заменить Gemini 3.6 Flash, в строке 20 "url=..." нужно вписать нужную после ".../models/"
